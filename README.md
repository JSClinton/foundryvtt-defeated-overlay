# Defeated Overlay

A tiny Foundry VTT module that makes the defeated (dead) status show as the large overlay icon covering the whole token, instead of the small status icon.

Useful with Monk's Combat Details "Automatically set defeated", which applies the status without the overlay.

## Install

In Foundry: **Add-on Modules → Install Module**, paste this manifest URL:

```
https://raw.githubusercontent.com/JSClinton/foundryvtt-defeated-overlay/main/module.json
```

Then enable **Defeated Overlay** in your world.
